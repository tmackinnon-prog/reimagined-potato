# Individualized Program Plan (IPP) — fillable template

A fillable Microsoft Word (`.docx`) Individualized Program Plan built to the
LYNX/ursa IPP layout and aligned to Alberta Education Special Education /
Inclusive Education standards. Teachers complete one copy per student.

- **`IPP_Template_2025-2026.docx`** — the deliverable. Open in Microsoft Word.
- **`build_ipp.py`** — the generator (run `python3 build_ipp.py` to rebuild).

## How it is filled in

The document uses Word **content controls**, so it stays fully editable — no
form protection or password is required. Click any control and type or choose:

| Control | Where |
|---|---|
| **Fillable text boxes** (blank) | Student name, parent/guardian, ASN, address, phone numbers, emails, dates, and every free-text cell |
| **Drop-down: Reporting Period** | Choose **1**, **2**, or **3** near the top (and in the page header) |
| **Drop-downs: Areas of Strength / Areas to Improve** | Student strengths & weaknesses (strengths-based options after Gemm Learning) |
| **Drop-down: Goal Topic** | Numeracy, Literacy, Time-Management, Self-Advocacy, Best Work, Organization, Attention, Emotional Regulation |
| **Check boxes** | Required Classroom Accommodations, and per-goal online-synchronous Strategies |

## Reporting periods & collating previous IPPs

- **Period 1** — fall baseline.
- **Periods 2 and 3** — winter/March and spring/June reviews. Open the
  student's previous IPP and copy each prior objective, strategy and result into
  the matching **November / March / June** cell so a single document collates the
  whole year before you add the new review. (A `.docx` cannot pull those cells in
  automatically; the November/March/June columns are laid out so the carry-over
  is a straight copy/paste.)

## Goal format

Each long-term goal reads:

> By **____**, *student* will **[goal topic]** **____** out of five instances as
> observed by teacher.

## Compatibility

Content controls (drop-downs, check boxes, fillable text) are fully supported in
Microsoft Word (desktop and Microsoft 365). Google Docs and LibreOffice open the
document but render some controls as static text; use Word for the interactive
experience.
